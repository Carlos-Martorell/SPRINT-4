Jokes, Weather & Fun | A Modern Web App

📘 Overview

This is a dynamic web application created to practice modern front-end development. It allows users to fetch jokes from two different APIs, rate their humor, and see the current weather for a specified location. The project was built using Vite and TypeScript, focusing on integrating multiple external APIs and creating a responsive, interactive user experience.

✨ Key Features

Jokes on Demand: Fetches jokes from two separate APIs (Dad Jokes and Chuck Norris Jokes) for variety.

Real-time Weather: Displays current weather conditions by fetching data from a third API.

Dynamic Backgrounds: The page background changes randomly from a selection of images with every new joke.

User Rating System: A simple rating system to score each joke.

Responsive Design: Built with Tailwind CSS for a sleek, mobile-friendly interface.

📁 Project Structure

index.html — The main interface for the application.

/src/main.ts — The primary entry point for the app logic.

/src/acuditsapp/ — Contains the joke-fetching logic for both APIs.

/src/rating-app/ — Manages the user rating system logic.

/src/weatherapp/ — Handles API calls and displaying weather data.

/src/assets/ — Stores all local assets, including the background images.

/src/style.css — Custom styles, including the classes for the dynamic backgrounds.

/package.json — Defines project dependencies and scripts.

🧪 Tech Stack

Vite — A fast, modern build tool.

TypeScript — A strongly typed language for building robust applications.

Tailwind CSS — A utility-first CSS framework.

FontAwesome — For the rating and weather icons.
